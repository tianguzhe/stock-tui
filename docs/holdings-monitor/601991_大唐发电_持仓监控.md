| 背离 | 无 | 无票 |

**根因**：`evalBullBear` 的六个维度全部是"指标衍生"的，**没有任何一项直接读当日价格行为**——跌停、跳空、单日暴跌这类最强烈的市场信号完全不进入投票。

**这是引擎缺陷而非数据问题**。在修复前，凡遇涨跌停/跳空标的，BULLBEAR 行一律需人工复核，不可直接采信。本股已由消息面核实独立否决，结论不受影响。
