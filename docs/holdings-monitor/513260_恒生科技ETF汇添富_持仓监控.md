## score 68 与 verdict 偏空(3/6) 如何调和

**二者量的不是同一个东西，也不是同一时间尺度**：

| | `SCORE=68` | `verdict=偏空` |
|---|---|---|
| 性质 | 固定尺**结构分**（历史可比） | **加权投票**，每维只一票 |
| 主要贡献 | ma=+10、macd=+8（慢变量） | TD/背离/OBV（快变量，**不进 score**） |
| 时间尺度 | 周–月级均线与动量结构 | 天–周级位置与拥挤度 |

关键在于 `BULLBEAR` 刻意压低了结构票：因 `ADX=14.98 < 20`，趋势维度只投出 w1 弱票，**SAR/ST 双多不另计**（ATR 系与 DMI 同维）。所以 3 vs 6 不代表结构崩了，而是"结构票被无趋势状态打折 + 择时票全在空方"。
