# 持仓心得 — 两个月实战总结

> 写于 2026-07-08 ｜ 来源：2026-05 至 2026-07 实盘交易复盘
> **免责**：个人交易记录与反思，不构成投资建议。

---

## 一、分批退出，留有余地

**教训**：不要一次性清空仓位。

止损触发时全仓杀出，看似纪律严明，实则可能割在最低点。市场极端超卖后的反弹往往迅猛且短暂——一把清空就只能眼睁睁看价格回升，心态崩塌后更容易追高回补，形成"割在底、追在顶"的恶性循环。

**实证**：工业富联 07-03 减仓2手@64.02（实亏-751元），留1手观察。07-08 反弹+3.50%至66.01，浮亏从-15.4%收窄至-12.45%。若当时全清，这3.50%的反弹就彻底错过了。

**规则**：
- 止损信号触发时，先减仓至安全仓位（如减至1-2手），保留观察仓
- 反弹确认（放量+SAR翻多）后再决定是否回补
- 只有在SAR/ST双空+score极弱+无任何底部信号时，才考虑全清

---

## 二、不盲目加仓，拒绝套在山腰

**教训**：在不了解的行情下盲目加仓，是亏损放大的最大根源。

"跌了就补"是散户最致命的本能反应。下跌趋势中的每一次"便宜"都可能只是半山腰。没有趋势确认信号（SAR/ST翻多、ADX>25、放量）的加仓，本质上是在用真金白银赌一个自己都不相信的反弹。

**实证**：中天科技 07-06 逆势加仓3手@46.48（SAR/ST双空下），从峰值利润+41.5%跌到-3.48%破成本仅用6个交易日。加仓时的理由是"跌多了该反弹"——但SAR/ST双空、ADX从49→36衰退、量比<0.8缩量，没有一条支持反弹判断。

**规则**：
- 加仓前必须过"建仓硬闸门"：SAR/ST双多 + ADX>25 + 量比>1.0
- 单只持仓成本不超过总仓25%
- 亏损状态下绝不加仓（除非SAR/ST翻多确认趋势反转）
- "跌多了"不是加仓理由，"趋势恢复了"才是

---

## 三、设定止损点位，学会认输

**教训**：没有止损的持仓等于赌博。止损不是认输，是活下来的前提。

每笔交易建仓时就必须明确止损价位，写在纸上、贴在屏幕上。价格到了就执行，不等收盘、不猜底、不问理由。犹豫一秒就是多亏一分。

**实证**：
- 圣泉集团：ST=55.48 是既定止损线，07-08 跌破至53.96（-6.48%），ST翻空触发清仓。若提前一天执行，可少亏约300元。
- 创新药ETF：SAR=0.653 是硬止损，07-08 跌破至0.650。虽然改用ST=0.616替代，但旧止损被击穿本身就说明风险在升级。

**规则**：
- 建仓时同时写下：止损价、止损距离%、触发后操作（减多少/清多少）
- 止损价只设一次，不后移（"再等等"是亏损的开始）
- 分级止损：预警价（减仓）→ 硬止损价（清仓），给自己两道防线
- 止损触发后复盘：是止损设错了，还是执行慢了？两者性质完全不同

---

## 四、跟随趋势，不做左侧

**教训**：永远不要做左侧交易。有趋势时再跟随，宁可晚一点进，不要早一点抄。

左侧交易（抄底、接飞刀、逆势加仓）的本质是"我觉得跌够了"——但市场不关心你觉得。趋势是最大的力量，SAR/ST双空就是空头趋势，不要跟它对着干。

**实证**：
- 中天科技：SAR/ST双空下"抄底"加仓，结果连跌6日-34.2%
- 泛微网络：SAR/ST双空下持有，-28.34%深度套牢
- 工业富联：等S底9*完成后07-08反弹+3.50%，虽然SAR/ST仍双空，但底部信号确认后至少没继续亏

**PERF 数据佐证**：
- 中天科技 趋势跟随多头 win10=70%——说明**有趋势时跟对的概率很高**
- 泛微网络 趋势跟随多头 win10=35%——说明**没趋势时做多几乎必亏**
- 三花智控 趋势跟随多头 win10=50%/avg=+0.07%——震荡型个股，追涨无效

**规则**：
- 建仓前过闸门：SAR/ST双多 + ADX>25 + 量比>1.0 + PERF趋势跟随win10≥50%
- 四条缺一不可，缺一就不做
- 左侧信号（底背离/超卖反转）只放底仓≤20%试错，不进主仓
- "趋势筛子"只作告警器，不作主仓来源——每只都必须基本面复核

---

## 附：核心纪律速查

```
1. 分批退出 → 留观察仓，不全清
2. 不盲目加仓 → 过闸门才加，亏损不补
3. 设止损 → 建仓时写死，到了就执行
4. 跟趋势 → SAR/ST双多才做多，双空绝不碰
```

> **一句话总结**：管住手，等信号，到了就做，错了就认。
