## ⚠️ 与短线仓的隔离规则（最重要，先看这条）

| 项目 | 红利仓（本文档） | 技术纪律短线仓（`.holdings`） |
|---|---|---|
| 目标函数 | 股息现金流 | 价差 |
| 卖出依据 | **每股分红下调** | SAR/ST 破位、score 走弱 |
| 下跌时 | **越跌越买**（攒股数） | 加仓闸门拦截摊平 |
| 持有期 | ≥ 1 年（免红利税） | 日/周级 |

🔴 **红利仓不写入 `.holdings`**。写进去会被 `stockdb screen` 按短线纪律评估，输出 `⚠️SAR/ST双空`、`🚫禁止加仓` 等警示——那套规则是为价差仓设计的，用在这里会导致在最该加仓时被拦住。本仓的记账、盈亏、再平衡**只在本文档进行**。

代价：`cmd/watch` 看不到本仓实时行情，需自行在券商 App 查看。这是刻意的取舍。

1. **档位只决定节奏，不决定去留**。跌破三档也不该恐慌——分红没下调时，更低的价格 = 更高的股息率，那正是目标。

## 🔄 半年再平衡（每年 2 月中旬 / 8 月中旬）

时点选在年报与半年报披露完毕、分红方案明朗之后。

### 第一步：分红体检（决定去留，优先级最高）

逐只核对，**任一红线触发即处理**：

| 红线 | 处理 |
|---|---|
| 最新方案**每股分红金额下调** | 🔴 减半或清出，换入池内替代标的 |
| 净利**连续两年**下滑 **且** 派息率 > 70% | 🔴 减半 |
| 股东回报规划变更（下调承诺比例） | 🔴 清出 |
| 仅股价下跌、分红未动 | 🟢 **不处理，反而是加仓机会** |

**当前需重点盯的**：
- **海尔智家** — 分红率承诺 2026 不低于 58%、2027-2028 不低于 60%（2025 为 55%）。**承诺未兑现即触发红线**
- **招商银行** — 净息差 1.83%（Q1 −8BP），跌破 1.70% 需警惕
- **中国平安** — 派息率仅 36.4%，缓冲最厚，风险最低
- **伊利股份** — 2026Q1 归母 +10.68%、扣非 +15.11%，四只中唯一利润加速

### 第二步：权重再平衡（**优先用股息和新增资金，不卖出**）

红利仓的核心是攒股数，卖出会**永久减少**未来的股息流。因此：

| 偏离目标权重 | 动作 |
|---|---|
| < 5pct | 不动 |
| 5 ~ 10pct | **把期间收到的股息全部投向权重最低的那只** |
| > 10pct | 优先仍用现金补低配；仅当某只超 40% 时才考虑减持 |
| 触发第一步红线 | 才允许卖出 |

### 第三步：股息再投资

期间收到的现金红利**全部投回本仓**，按第二步规则分配到权重最低的标的。这是攒股数最便宜的一档——不需要新增本金。
