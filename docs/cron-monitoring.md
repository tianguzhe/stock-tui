# 盘中监控 Cron 指南

每 2 分钟运行 `go run ./cmd/watch/`，监控持仓异动（实时行情 + 技术面 + 浮盈）。

## 快速启停

在 Claude 对话中说：
- **启动**："开启 cron" / "开始监控"
- **停止**："停止 cron" / "暂停监控"

## 时区转换

A 股交易时间固定为 **BJT（UTC+8）**：09:30-11:30、13:00-15:00。
Cron 使用本地时区，需将 BJT 转为本地时间：

```
本地小时 = BJT小时 - (8 - 本地UTC偏移)
```

例：PDT（UTC-7）→ `BJT小时 - 15`，BJT 09:30 → PDT 前一天 18:30。

**各时区小时字段速查：**

| 时区 | 偏移 | BJT 09:30 | BJT 15:00 | cron 小时字段 |
|------|------|-----------|-----------|---------------|
| PDT | -7 | 18:30 前日 | 00:00 | `18,19,20,21,22,23,0` |
| PST | -8 | 17:30 前日 | 23:00 | `17,18,19,20,21,22,23` |
| EST | -5 | 20:30 前日 | 02:00 | `20,21,22,23,0,1,2` |
| CST | +8 | 09:30 | 15:00 | `9,10,11,12,13,14` |
| JST | +9 | 08:30 | 14:00 | `8,9,10,11,12,13` |

> 午休时段（12:00-13:00）也会触发，返回昨收数据，不影响正确性。

## CronCreate 调用

```json
{
  "cron": "*/2 {小时字段} * * 0-5",
  "durable": true,
  "recurring": true,
  "prompt": "运行 `go run ./cmd/watch/` 并展示异动监控结果"
}
```

- `durable` — 持久化到 `.claude/scheduled_tasks.json`，重启恢复
- `recurring` — 循环执行，7 天自动过期

## 手动测试

```bash
go run ./cmd/watch/   # 运行一次监控
cat .holdings          # 查看持仓
```

## 错误处理

| 场景 | 行为 |
|------|------|
| 网络超时 | 下次触发自动重试 |
| API 返回空 | 显示"暂无数据"，不中断 |
| `.holdings` 缺失 | 报错退出 |

## 持仓文件

`.holdings` — 逗号分隔，`#` 注释，格式 `代码:成本:手数`：

```
sh601138:61.551:2,sz159858:0.712:151,sh600909:9.318:9,sh513260:1.143:66,sh512480:1.351:8
```

## 监控输出

每轮输出包含：实时行情（价格/涨跌%/成交额/换手率/市值）、仓位（成本/手数/浮盈/距成本%）、技术面（SAR/ST/ADX/KDJ/RSI/WR/MACD/MFI/SCORE）、异动预警（涨跌阈值/量比/惜售）。
